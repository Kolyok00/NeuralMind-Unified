## 🚀 Indítási Útmutató

### Gyors Indítás
```bash
# 1. Repository klónozása
git clone <repository-url>
cd NeuralMind-Unified

# 2. Környezeti változók beállítása
cp env.example .env
# Szerkeszd a .env fájlt a saját API kulcsaiddal

# 3. Szolgáltatások indítása
./start_unified.sh start

# 4. Állapot ellenőrzése
./start_unified.sh status
```

### Szolgáltatás URL-ek
- **API Gateway**: http://localhost
- **FusionAI API**: http://localhost:8888
- **VTuber Service**: http://localhost:8080
- **Grafana Dashboard**: http://localhost:3000
- **n8n Workflows**: http://localhost:5678
